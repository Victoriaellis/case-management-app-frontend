## Case Management App – Frontend
This is the frontend for the Case Management App, developed using Next.js and TypeScript. It provides a responsive and modern interface for managing tasks, including adding, updating the status and deleting tasks.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

## Tests
This project uses Jest for testing.​

To run tests:

Using npm:
```bash
npm test
```
